template<typename Counter>
Trial run_trial ( int num_threads,
counter_t increments_per_thread )

Runs one timed trial in which worker threads increment a shared counter.

All workers synchronize with the calling thread at a barrier before incrementing, avoiding staggered worker startup. The elapsed time covers the interval from the caller's barrier release through completion of all worker joins.

Explicitly instantiated in benchmark.cpp for UnsafeCounter, MutexCounter, AtomicCounter, and SpinLockCounter. Supporting another counter type requires adding an instantiation there.

Template Parameters
CounterCounter type providing increment() and get() operations.
Parameters
num_threadsNumber of worker threads; must be greater than zero.
increments_per_threadNumber of increments each worker performs; must be non-negative.
Returns
The elapsed time and whether the final value matched num_threads * increments_per_thread.
